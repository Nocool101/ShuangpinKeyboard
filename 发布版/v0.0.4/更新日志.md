## 一、这一版改了什么

一句话：**键盘上能调设置了，长句能一段一段挑了，乾能打出来了。**

### 1. 键盘上多了颗 ⚙，布局和大小当场就能调

以前改键盘设置只有一条路：系统设置 → 语言和输入法 → 键盘 → 设置，十个人九个找不到。
现在**候选区左边**有颗 ⚙，点一下就开：

| 能改什么 | 说明 |
|---|---|
| 键盘形态 | 全键盘 / 单手·右手 / 单手·左手 |
| 韵母位排法 | 固定小鹤（默认）/ 拇指优先 |
| 键盘高度 | 70% ~ 140%，滑杆拖着就变 |
| 键盘宽度 | 50% ~ 100%（单手模式有效） |

面板浮在键盘上面，**拖着滑杆能看着键盘实时变大变小**，改完立刻生效，不用重启输入法。

那颗 ⚙ 在单手右手模式贴着屏幕左边缘，正好落在**常用标点竖列的顶端**——跟系统输入法把工具键放在那一列上方是一个道理。

### 2. 右下角「发送 / 换行 / 前往 / 完成」键变大了

它是最常用的键，却原来只有 34 dp 宽，拇指得瞄准那个角才按得到。

现在**单手 46 dp、全键盘 84 dp**，右边贴着屏幕边不动、**往左长**——长出来的那块是从空格键那儿借的。

**跟退格键之间的空隙一点没少**：那段空隙是单独算出来的，手指从退格滑过去照样落空，不会误发消息。

### 3. 长句能一段一段挑了

打「北风卷地白草折」，以前整句就是一坨，想改中间那段做不到。
现在候选栏**按音节分组往后排**：

```
北风卷地白草折          ← 整句
│ 北风 被封 背风 被缝…   ← 第①组（bei feng）的词，词优先
│ 背 杯 被 北 风 封 丰…  ← 第①组的字
│ 卷地 涓滴 …            ← 第②组（juan di）
```

- **词在字前面**——词比字准，先给词
- 组与组之间有一根细竖线，一眼看得出分到哪了
- 选完一段，**后面没选的拼音留在会话里**，接着挑下一组
- 挑完上屏，**整句会被记住**，下次打同样的拼音第一个候选就是你上次挑的那句

### 4. 选完一段直接看到下一段，不再被推荐词挡路

以前选完「北风」，候选栏第一个跳出来的是「这 吹 狼 行 滔滔」这些**下一词建议**，得划过去才能看到「卷地」那组。

现在**下一词建议挪到候选栏最后**——它是"这一句上屏之后接下来打什么"，跟"这一句的每一段能挑什么"本来就是两件事，不该插在中间挡路。

### 5. 「乾」能打出来了（还有 35 个字）

**乾、覆、蒙、著、徵、於、卻、剋、瞭、祕…** 这 36 个字以前**根本打不出来**。

原因是词库导入时按繁简表滤繁体字，而繁简表里有一条 `乾 → 干`（"干燥"的繁体写法），于是乾被当成繁体字整个滤掉了——连带「乾隆」「乾坤」「承乾宫」这些词也没了。

乾本身是**规范简体字**（《通用规范汉字表》里就有）。现在导入时按 8105 字表判定：**在字表里的就是规范简体字，繁简表怎么说都不算数**。

词表顺带补回 1520 条。

### 6. 选字面板和候选栏，每轮输入都回第一页

以前打完一段、翻到第 3 页，再打同样的拼音——内容没变，**滚动位置还留在第 3 页**，看起来像"候选没更新"。
现在新一轮输入一律翻回第一页。

选字面板也是同一个毛病（翻到第 3 页挑了个字，重新打开还在第 3 页），一并修了。

### 7. 跟词库完全重复的用户词条目不再占着第一

「学整句」时顺手记下的那条，往往跟词库里的原词一模一样。它没有任何用处（词库本来就有），
却按"打得多的在前"排序**压过了你真正挑的那句**。

现在这类冗余条目不再参与候选排序——**你自己挑的用法排第一**。

## 二、怎么用

### 键盘设置

点候选区左边的 **⚙** → 拖滑杆调大小 / 点形态切换 → 改完直接生效。

### 长句分段挑

1. 打完整句（`bw ft jr di bd cc ve`）
2. 候选栏第一格是整句，**往右滑**看到第①组
3. 点组里的词（比如「北风」）
4. 上屏「北风」，后面的拼音留在会话里，候选栏接着给第②组
5. 重复，直到整句挑完

### 关于「乾」

打 `qm`（qian）就能看到乾了。词库里还多了一批词：「乾隆」「乾坤」「覆灭」「蒙蔽」……

## 五、已知限制

- **「百草折」这种非词库的组合**，得自己挑出来才会被记住（第一次挑完上屏才生效）
- 键盘高度调到 70% 时字母键会明显变小，拼音角标也跟着缩——那个尺寸是给「拇指够不着」的人用的
- 分组候选是按**分词结果**切的，词库里没有的词（比如「卷地」）只能从组里的**字**里挑
