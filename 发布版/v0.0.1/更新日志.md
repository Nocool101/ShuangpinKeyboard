## 一、这是什么

一个 Android 原生**双拼输入法**。核心是「**双层标签键面**」：

- 26 个物理键常驻，按下声母后**只换标签、不换布局**
- 声母位显示声母（`zh`/`ch`/`sh` 直接写在键面上）
- 韵母位显示**这个键在当前声母下的那个韵母**，无效键整体变灰

小鹤双拼里天然有 9 个键对应两个韵母（`k`=ing/uai、`s`=ong/iong、`x`=ia/ua、
`l`=iang/uang、`o`=o/uo、`v`=ü/ui、`y`=un/ün、`t`=üe、`r`=er/uan/üan）。
这里利用「声母一旦确定，合法韵母集合也随之确定」这一事实**预先消解**——
用户按不下去错的键。

## 二、这一版有什么

### 键盘

- **韵母位固定在小鹤标准键位**：每个韵母永远在它那个键上（`ao`→`c`、`ian`→`m`、
  `uang`→`l`）。换声母也不用重新认位置。
- 三种形态：单手·右手（默认）、单手·左手、全键盘；字母区占屏宽 86%，留白区放常用标点列。
- 数字面板按常见样式重做（顶行符号 + 左列 % − × + 中区 3×4 + 右列 退格/空格/动作键）。
- 候选栏横滑翻页 + 页码 + **每个字上方标拼音角标**（点角标可单独改这个字）。

### 输入

- **整句上屏**：打完一段话按空格，候选栏第一条直接上屏。
- **上屏只有空格一个入口**：候选、云端给的「下一词」建议、滑动选中的那条全归空格。
- **拼音打错了，点一下就能改**：预编辑区里的拼音可以点，光标停在那一处，
  退格删的是**光标前面那个字**，接着打的字**插在光标处**，后面打好的音节跟在后头。
  > 例：要打「仙人抚我顶」却打成了 `xianrifuwoding` → 点在 `ri` 后 → 退格删掉 `i`
  > → 补 `en`（小鹤里 en 在 `f` 键）→ 候选栏第一条就是「仙人抚我顶」。
- **自动纠错**：
  - 声母记混（`z↔zh`、`c↔ch`、`s↔sh`…）
  - 韵母记混（`an↔ang`、`en↔eng`…）
  - **韵母键按错**：原串在词库里根本没有时，把「同声母换任意韵母」全试一遍
  - 纠错候选必须比原串首选常用得多（词频差 8 倍）且是整词才展示
- **自学习词库**：你打过的词，下次打同样的拼音**排第一**。
  词库里根本没有的词也能学（「炼气士」「炼气」「气士」这类专有名词）。
  词条只存在本机（`user_dict.tsv`），不上传、不联网；设置页可看条数、可一键清空。
- **选字面板**：候选栏右端 `⌄` 展开，左列拼音、右列候选字网格，逐个音节挑字。
- **语音输入**：按住空格说话，松手停止（需在设置里配好识别接口并授予录音权限）。

### 右下角那颗键（动作键）

同一颗键，按宿主变身：

| 宿主 | 键面 | 点击之后 |
|---|---|---|
| 微信 / QQ 等聊天工具 | **发送** | 把这条消息发出去 |
| 多行文本框（备忘录、评论框） | **换行** | 换到下一行 |
| 浏览器地址栏 | **前往** | 搜索 / 打开网址 |
| 普通单行输入框 | **完成** | 收尾这一轮输入 |

判定看三样：宿主包名 + 编辑框声明的 action + 是不是多行。
（聊天软件必须在多行之前判——微信的聊天框既不声明 action 又是多行的。）

### 云端能力（**默认关闭**，需要自己配）

| 功能 | 作用 |
|---|---|
| 下一词预测 | 打完一个词，候选栏给出「接下来最可能打的词」 |
| 按上文消歧 | 结合上文重排候选（「智慧」还是「指挥」） |
| 整句纠错 | 整句话里的错别字，给一个改正版候选 |

两种接法：**自建服务**（key 留在服务端，推荐）或**直连厂商**（key 存在本机）。
仓库里有 `tools/lexeme_server.mjs`，也可以接 MiniMax / 阶跃 / 任意 OpenAI 兼容接口。

## 三、怎么装

1. 把 `双拼输入法-v0.0.1.apk` 传到手机
2. 点它安装（debug 包，需要允许「安装未知来源应用」）
3. **系统设置 → 语言和输入法 → 虚拟键盘 → 启用并切换到「双拼输入法」**
   （调不出键盘时，长按地球键也能进设置页）
4. 桌面上有图标，点图标进设置页（云端、语音、键盘形态都在那儿）

> 荣耀 / 华为等 ROM 偶尔会把输入法抢回厂商输入法，
> 重新切换一次即可；也可以在系统设置里把它设为默认。

## 四、已知限制

- **APK 69 MB**：因为内置了端侧重排模型（8 MB ONNX）+ 全量 ONNX Runtime（31 MB）。
  这是有意为之——用户明确说了体积不重要，功能做好优先。
- **端侧重排模型**只在等长候选里用：混长短候选会让它偏向单字，
  实测整句准确率从 77% 砸到 32%。
- **微信的「发送」**依赖微信自己的「按回车键发送消息」设置；
  没开的话，宿主不认 `performEditorAction` 时会退化成发回车键事件。
- **云端功能默认关闭**：开了之后输入内容会发到端点指向的服务，这是隐私决定。
- **词库**来自 [rime-ice（雾凇拼音）](https://github.com/iDvel/rime-ice)，
  约 78 万条词、4.3 万候选字。
